P2.3  ATM Machine Simulation   [Medium]  [LOOP, EXIT WHEN, running balance, transaction counter] Problem Statement:  Simulate an ATM: initial_balance = roll_no*500+5000. Use LOOP with a simulated menu (v_choice variable). Rules: (1) Withdrawal must be >0, multiple of 100, <=10000 per txn, <=balance. (2) Each condition has a specific error message. (3) Count total successful transactions. (4) EXIT when v_choice=3 (Exit) OR balance=0. Run at least 4 iterations by setting v_choice in DECLARE. Print transaction receipt for each and final summary: txns done, total withdrawn, closing balance. Worked Example:  Roll#1: balance=5500, withdraw 500,1000,500 => closing=3500, 3 txns | Roll#25: balance=17500 

//answer

SET SERVEROUTPUT ON;

DECLARE
    v_roll_no NUMBER := 34;
    v_balance NUMBER := v_roll_no * 500 + 5000;
    v_choice NUMBER;
    v_withdraw NUMBER;
    v_txn_count NUMBER := 0;
    v_total_withdraw NUMBER := 0;
    v_iteration NUMBER := 1;
BEGIN
    DBMS_OUTPUT.PUT_LINE('Initial Balance: Rs.' || v_balance);

    LOOP
        -- Simulated choices
        IF v_iteration = 1 THEN
            v_choice := 1;
            v_withdraw := 500;
        ELSIF v_iteration = 2 THEN
            v_choice := 1;
            v_withdraw := 1000;
        ELSIF v_iteration = 3 THEN
            v_choice := 1;
            v_withdraw := 1500;
        ELSIF v_iteration = 4 THEN
            v_choice := 1;
            v_withdraw := 2000;
        ELSE
            v_choice := 3;
        END IF;

        EXIT WHEN v_choice = 3 OR v_balance = 0;

        IF v_withdraw <= 0 THEN
            DBMS_OUTPUT.PUT_LINE('Error: Amount must be greater than 0');

        ELSIF MOD(v_withdraw, 100) <> 0 THEN
            DBMS_OUTPUT.PUT_LINE('Error: Amount must be multiple of 100');

        ELSIF v_withdraw > 10000 THEN
            DBMS_OUTPUT.PUT_LINE('Error: Maximum withdrawal is Rs.10000');

        ELSIF v_withdraw > v_balance THEN
            DBMS_OUTPUT.PUT_LINE('Error: Insufficient balance');

        ELSE
            v_balance := v_balance - v_withdraw;
            v_txn_count := v_txn_count + 1;
            v_total_withdraw := v_total_withdraw + v_withdraw;

            DBMS_OUTPUT.PUT_LINE('Withdrawn: Rs.' || v_withdraw);
            DBMS_OUTPUT.PUT_LINE('Remaining Balance: Rs.' || v_balance);
        END IF;

        v_iteration := v_iteration + 1;
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('Total Transactions: ' || v_txn_count);
    DBMS_OUTPUT.PUT_LINE('Total Withdrawn: Rs.' || v_total_withdraw);
    DBMS_OUTPUT.PUT_LINE('Closing Balance: Rs.' || v_balance);
END;
