P1.19  Bank Branch Hierarchy — Nested Scope   [Medium]  [Nested blocks, block labels, 
scope rules, compile errors] Problem Statement:  Model a bank as 3 nested blocks. 
Outer <<bank>>: v_bank := 'LJ Bank', v_total_deposit := 0. Middle <<branch>>:
 v_branch := your home city, add a deposit into bank.v_total_deposit. Inner <<counter>>: 
 declare v_token, print bank name + branch + token — proving inner can read BOTH outer 
 levels. After the inner block ends, add a commented-out line in the middle block that 
 tries to print v_token, run once uncommented, and note the exact error (PLS00201). 
 Finally print total deposit at bank level.
DECLARE
    v_bank VARCHAR2(50) := 'LJ Bank';
    v_total_deposit NUMBER := 0;
BEGIN
    <<branch>>
    DECLARE
        v_branch VARCHAR2(50) := 'Ahmedabad';
        v_deposit NUMBER := 34 * 1000;
    BEGIN
        bank.v_total_deposit :=
            bank.v_total_deposit + v_deposit;

        DECLARE
            v_token NUMBER := 1;
        BEGIN
            DBMS_OUTPUT.PUT_LINE(
                bank.v_bank || ' | ' ||
                v_branch || ' | Token ' ||
                v_token
            );
        END;

        -- DBMS_OUTPUT.PUT_LINE(v_token);
        -- Uncommenting this causes PLS-00201
        -- because v_token is outside its scope.
    END;

    DBMS_OUTPUT.PUT_LINE(
        'Total Deposit: Rs.' ||
        v_total_deposit
    );
END;
