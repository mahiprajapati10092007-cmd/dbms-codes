P1.6  Bank Interest Calculator — SI and CI   [Medium]  [Arithmetic, POWER, formatted output]
Problem Statement:  Build a bank interest calculator. Variables: principal, rate (%), years. 
Calculate: (1) Simple Interest = P*R*T/100, (2) Compound Interest = P*(1+R/100)^T - P using 
POWER function, (3) Final amounts for both. Print a comparison: show SI vs CI difference. If CI > 
SI by more than 10%: print "Tip: FD is better than savings account for this amount." Use 
TO_CHAR to format amounts with commas.



-->answer


DECLARE
    v_roll NUMBER := 34;
    v_p NUMBER;
    v_r NUMBER := 7;
    v_t NUMBER := 3;
    v_si NUMBER;
    v_ci NUMBER;
    v_final_si NUMBER;
    v_final_ci NUMBER;
    v_diff_pct NUMBER;
BEGIN
    v_p := v_roll * 1000;

    v_si := v_p * v_r * v_t / 100;

    v_ci := v_p *
            POWER(1 + v_r / 100, v_t) - v_p;

    v_final_si := v_p + v_si;
    v_final_ci := v_p + v_ci;

    v_diff_pct := (v_ci - v_si) / v_si * 100;

    DBMS_OUTPUT.PUT_LINE('Principal: Rs.' || v_p);
    DBMS_OUTPUT.PUT_LINE('Rate: ' || v_r || '%');
    DBMS_OUTPUT.PUT_LINE('Years: ' || v_t);
    DBMS_OUTPUT.PUT_LINE(
        'Simple Interest: Rs.' ||
        TO_CHAR(v_si, '99,999.99')
    );
    DBMS_OUTPUT.PUT_LINE(
        'Compound Interest: Rs.' ||
        TO_CHAR(v_ci, '99,999.99')
    );
    DBMS_OUTPUT.PUT_LINE(
        'Final Amount (SI): Rs.' ||
        TO_CHAR(v_final_si, '99,999.99')
    );
    DBMS_OUTPUT.PUT_LINE(
        'Final Amount (CI): Rs.' ||
        TO_CHAR(v_final_ci, '99,999.99')
    );

    IF v_diff_pct > 10 THEN
        DBMS_OUTPUT.PUT_LINE(
            'Tip: FD is better than savings account for this amount.'
        );
    END IF;
END;
