P1.1  My First PL/SQL Block   [Easy]  [Block structure, DBMS_OUTPUT, SET SERVEROUTPUT 
ON]
Problem Statement:  Write an anonymous block: (a) Print your name and roll number. (b) Declare 
v_message VARCHAR2(100), assign "Welcome to PL/SQL!", print it. (c) Calculate roll_no MOD 7 
+ 1 and call it your "lucky number", print it. Run SET SERVEROUTPUT ON first. Observe: what 
happens if you forget it?
SET SERVEROUTPUT ON;


//answer

DECLARE
    v_name VARCHAR2(50) := 'Mahi Prajapati';
    v_roll NUMBER := 34;
    v_message VARCHAR2(100) := 'Welcome to PL/SQL!';
    v_lucky NUMBER;
BEGIN
    v_lucky := MOD(v_roll, 7) + 1;

    DBMS_OUTPUT.PUT_LINE('Name: ' || v_name);
    DBMS_OUTPUT.PUT_LINE('Roll Number: ' || v_roll);
    DBMS_OUTPUT.PUT_LINE(v_message);
    DBMS_OUTPUT.PUT_LINE('Lucky Number: ' || v_lucky);
END;
