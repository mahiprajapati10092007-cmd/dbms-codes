P2.4  Loops and Patterns   [Easy]  [FOR LOOP, REVERSE, nested loops, pattern printing] Problem Statement:  Part A: Multiplication table of (roll_no MOD 9 + 2) from 1 to 20 using FOR loop. Part B: Print all tables of 2,3,4,5 using nested FOR loops with LPAD alignment. Part C: Right-angled star triangle, height = 5 + roll_no MOD 5 (stars increase each row). Part D: Number pyramid: row 1 prints "1", row 2 prints "12", row 3 prints "123" etc. for 6 rows. Part E: Same triangle but REVERSE (tallest row first) using REVERSE keyword. 


//answer

SET SERVEROUTPUT ON;

DECLARE
    v_roll_no NUMBER := 34;
    v_num NUMBER;
    v_height NUMBER;
BEGIN
    v_num := MOD(v_roll_no, 9) + 2;
    v_height := 5 + MOD(v_roll_no, 5);

    -- Part A
    DBMS_OUTPUT.PUT_LINE('Multiplication Table of ' || v_num);

    FOR i IN 1..20 LOOP
        DBMS_OUTPUT.PUT_LINE(v_num || ' x ' || i || ' = ' || v_num * i);
    END LOOP;

    -- Part B
    DBMS_OUTPUT.PUT_LINE('Tables of 2, 3, 4, 5');

    FOR i IN 2..5 LOOP
        FOR j IN 1..10 LOOP
            DBMS_OUTPUT.PUT_LINE(i || ' x ' || j || ' = ' || LPAD(i*j, 3));
        END LOOP;
    END LOOP;

    -- Part C
    DBMS_OUTPUT.PUT_LINE('Star Triangle');

    FOR i IN 1..v_height LOOP
        DBMS_OUTPUT.PUT_LINE(RPAD('*', i, '*'));
    END LOOP;

    -- Part D
    DBMS_OUTPUT.PUT_LINE('Number Pyramid');

    FOR i IN 1..6 LOOP
        FOR j IN 1..i LOOP
            DBMS_OUTPUT.PUT(j);
        END LOOP;
        DBMS_OUTPUT.NEW_LINE;
    END LOOP;

    -- Part E
    DBMS_OUTPUT.PUT_LINE('Reverse Star Triangle');

    FOR i IN REVERSE 1..v_height LOOP
        DBMS_OUTPUT.PUT_LINE(RPAD('*', i, '*'));
    END LOOP;
END;
/
